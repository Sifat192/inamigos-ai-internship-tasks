## No-code ML demonstration

Task 3 explores the supervised learning workflow through flower classification:

- **Platform:** Google Teachable Machine.
- **Dataset:** Rose and sunflower categories from the TensorFlow Flowers dataset.
- **Training examples recorded:** 641 rose images and 699 sunflower images.
- **Held-out images recorded:** 20 images per class.
- **Training settings recorded:** 50 epochs, batch size 16, and learning rate 0.001.
- **Documentation:** Labelled examples, model training, and sample predictions.

The submission illustrates how a model learns from labelled images and produces predictions for new inputs. Individual prediction confidence scores are not a test-set accuracy measurement; the document does not report an aggregate test accuracy.

## AI & ML for social impact

The final task explores five proposed applications:

| Problem | Proposed application |
| --- | --- |
| Delayed identification of crop diseases | A computer vision assistant that flags visible signs of leaf disease for further assessment. |
| Unidentified student learning gaps | An adaptive learning assistant that suggests practice based on topic-wise performance. |
| Irregular bus arrivals | Arrival prediction and spacing alerts to support transport operators. |
| Incorrect waste segregation | Image-based waste recognition with disposal guidance based on local rules. |
| Surplus food and unmet community needs | Surplus forecasting and donation matching to support collection coordination. |

These are **concept proposals**, with suggested evaluation measures. They are not deployed systems or claims of measured community impact.

## Learning focus

- Communicating AI and ML concepts through familiar examples.
- Explaining the relationship between training data, learned patterns, and predictions.
- Exploring image classification through a visual, no-code platform.
- Identifying practical uses of AI and ML in community-oriented problems.
- Documenting workflows, limitations, and expected outcomes clearly.
